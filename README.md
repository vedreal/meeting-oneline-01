Entry for the [make.fun bounty "The Meeting That Should Have Been One Line"](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c) — write the single sentence that could have replaced an entire pointless meeting.

## The entry

> This meeting could have been an email, and the email could have been a thumbs-up.

## How it works

`main.py` writes ten fresh candidate one-liners, scores each against the
judge's criteria (single line that replaces the meeting, kills the meeting
outright, relatable office life, lands as a joke with a turn, stands alone),
picks the highest-scoring line, validates it against the gate (one line,
1–200 characters), and writes it to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```
